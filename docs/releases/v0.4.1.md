# Telemetry for Todoist v0.4.1 — draft

**Not ready to publish.** These notes describe the current release candidate;
the technical identity migration and release validation remain incomplete.

## Product focus

The former Todoist Assistant is now presented as Telemetry for Todoist, an
independent third-party integration for local-first Todoist activity analytics
and project history. The dashboard includes Overview, Project Timeline,
background cache refresh, Control Panel and Live Logs. Habit-labelled task data
is available in the dashboard API. Android remains a separate supported app.
A separate observer, stale-task maintenance and Codex executive review are not
implemented in this candidate.

Task Multiplication, task-tree/template import, the conversational assistant,
Gmail integration and Docker distribution are not part of the product.

## Upgrade and technical identity

The planned Python namespace `todometry`, distribution `telemetry-for-todoist`
and command `todoist-telemetry` have **not** been implemented. The current
candidate still uses `todoist`, `todoist-assistant` and the existing local state
paths. Tests cover reading representative v0.4.0 activity and project mappings
at those existing paths, including preserving incompatible cache files. They do
not establish migration to a renamed namespace or new paths. No upgrade claim
should be made for that future migration until it is implemented and tested.

The web backend still has runtime namespace injection; the intended FastAPI
dependency cleanup is incomplete. Publication checks reject the known identity
and web architecture debt, but do not replace product and migration validation.

## Packaging

Windows MSI/bootstrapper and macOS package, app and disk image builds have CI
workflows. Native build and install results must be verified on their respective
platforms for the final release. Current artifact names use legacy technical
identifiers; stable installer identifiers and existing local data require a
careful upgrade review before any renaming or publication.
